# Expense Tracker

A simple command-line Expense Tracker built with Python that helps users record, view, and manage daily expenses. The application stores data locally using a JSON file, making it lightweight, beginner-friendly, and easy to customize.

## Features

* Add new expenses
* View all recorded expenses
* Update existing expenses
* Delete expenses
* Store data persistently in a JSON file
* Display total expenses
* Simple command-line interface

## Technologies Used

* Python 3
* JSON

## Getting Started

### Clone the repository

```bash
git clone https://github.com/chethanraj429/Expense-tracker.git
```

### Navigate to the project directory

```bash
cd Expense-tracker
```

### Run the application

```bash
python main.py
```
